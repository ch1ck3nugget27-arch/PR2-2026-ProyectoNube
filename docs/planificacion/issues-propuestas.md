# Issues propuestas

Crear cada una en **GitHub → Issues → New issue** y asignarla a una persona concreta.

1. Completar el README con integrantes y estado actual
2. Subir el documento Word/PDF original a `docs/proyecto/`
3. Subir el Gantt original a `docs/planificacion/`
4. Subir la presentación a `docs/presentaciones/`
5. Cada integrante sube su `.txt` a `equipo/`
6. Ejecutar la app en cada computadora y reportar problemas
7. Agregar límite de imágenes por usuario
8. Crear `S3Storage` (o similar) con la misma interfaz que `LocalStorage`
9. Agregar miniaturas en la galería
10. Resolver la tabla de acciones de la auditoría (`docs/auditoria/`)
